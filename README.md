# FantasyBoard

A fantasy football draft board: consensus expert rankings, live ADP, and your own
custom rank order, all in one dense sortable table you can use during a live draft.

## Features

- **Consensus rankings + live ADP** — a seeded expert consensus ranking merged with
  average draft position pulled from ESPN's public fantasy endpoint.
- **Custom rank order** — drag-and-drop your own board in Edit Mode; persists to
  `localStorage`.
- **Draft tracking** — mark players drafted by you or an opponent, hide drafted
  players, undo a pick.
- **Δ (delta) column** — shows how far a player's ADP falls from expert consensus,
  a quick signal for values (green, ▲) vs. reaches (red, ▼).

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Refreshing rankings / ADP

Player data lives in `data/players.json`, generated by merging:

- `data/seed/expert-rankings.json` — a curated consensus ranking (~250 players).
- Live ADP, bye weeks, and rosters from ESPN's public fantasy API.

To regenerate it (e.g. for a new season, or to pick up roster/ADP movement):

```bash
npm run fetch:rankings -- --season=2026
```

The script prints a match-rate summary. If any seed names fail to match an ESPN
player (nicknames, suffixes, etc.), add an entry to `data/seed/name-aliases.json`
mapping the seed name to ESPN's name and re-run.

To update the underlying expert consensus order itself, edit
`data/seed/expert-rankings.json` directly, then re-run the fetch script.
